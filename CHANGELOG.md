# Changelog

## [0.1.0]

Чат:
- стриминг ответов, остановка генерации с сохранением написанного куска,
  повтор последнего ответа;
- вложения PDF/DOCX/XLSX/TXT из поля ввода (Streamlit >= 1.44, ниже — только текст);
- экспорт истории в PDF (fpdf2, кириллица через Noto/DejaVu);
- блоки рассуждения моделей в сворачиваемой секции, метаданные ответа;
- скроллируемая история, светлая/тёмная тема (тёмная — CSS-оверлей).

Анализ документов:
- map-reduce конвейер: план по сэмплу, чанки, накопительное резюме с автосжатием,
  финальный отчёт;
- извлечение текста из PDF/DOCX/XLSX/TXT;
- стратегии дробления: по структуре, regex-разделителю, абзацам, символам, с overlap;
- шаблоны типовых задач, рекомендация размера чанка от контекстного окна модели;
- экспорт в DOCX и Markdown, предпросмотр текста и оценка числа чанков до запуска.

Звонки и транскрибация:
- WAV -> внешний ASR-сервис -> анализ; шаблоны задач (причины обращений,
  referral-анализ, эскалации);
- пакетная транскрибация в единый .docx, предпросмотр транскриптов.

Провайдеры:
- Ollama (нативный API + автодетект OpenAI-режима), vLLM, любой OpenAI-compatible API;
- URL/ключ/доп. заголовки в UI и через .env, ручной ввод модели, если нет /v1/models;
- параметры генерации temperature/top_p/max_tokens;
- индикатор статуса подключения с TTL-кэшем проверки.

Инфраструктура:
- вкладки на st.fragment; результаты переживают перезапуски скрипта (session_state);
- docker-образ + compose, CI (ruff + pytest, включая AppTest-дым-тесты UI);
- разборчивые сообщения об ошибках подключения/аутентификации/TLS.
