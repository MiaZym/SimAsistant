# LLM Document Analyzer & Chat Service

Сервис для работы с LLM моделями: чат, анализ документов и обработка звонков на базе Streamlit.

## 🚀 Возможности

### 1. **Чат с LLM**
Простой и удобный интерфейс для общения с различными LLM моделями.

### 2. **Анализ больших документов**
Интеллектуальный анализ документов с автоматическим дроблением на чанки:
- 📄 Поддержка форматов: PDF, DOC/DOCX, XLS/XLSX, TXT
- 🧩 Интеллектуальное дробление текста (по диалогам, разделителям, абзацам, символам)
- 🔄 Стриминг ответов в реальном времени
- 💾 Автосохранение прогресса
- 📊 Детальная статистика
- 📥 Экспорт результатов в Markdown

**Режимы анализа:**
- **Общий анализ** — универсальный анализ любых документов
- **Всплеск обращений** — специализированный режим для анализа транскриптов звонков

### 3. **Анализ звонков**
Обработка аудиофайлов:
- 🎙️ Автоматическая транскрибация WAV файлов
- 📝 Склейка диалогов в общий текст
- 📊 Анализ с выявлением причин обращений

## 📋 Требования

- **Docker** и **Docker Compose**
- **Ollama** или **vLLM** (локальный LLM сервер)
- Опционально: сервис транскрибации для обработки аудио

## 🛠️ Быстрый старт

### Шаг 1: Запустите LLM сервер

**Ollama (рекомендуется):**
```bash
# Установите Ollama с https://ollama.ai/
# Запустите модель, например:
ollama run llama3.2
```

**vLLM:**
```bash
pip install vllm
python -m vllm.entrypoints.openai.api_server --model meta-llama/Llama-3.2-3B-Instruct
```

### Шаг 2: Настройка конфигурации

```bash
# Скопируйте пример конфигурации
cp .env.example .env

# Отредактируйте .env при необходимости
# По умолчанию настроено для локального использования
```

Содержимое `.env`:
```env
TRANSCRIBE_URL=http://host.docker.internal:8077/api/v1/transcribe
TRANSCRIBE_FILE_FIELD=file

OLLAMA_URL=http://host.docker.internal:11434
VLLM_URL=http://host.docker.internal:8000

LLM_TIMEOUT_SEC=600
```

### Шаг 3: Запуск сервиса

```bash
# Соберите и запустите контейнер
docker compose up --build

# Или в фоновом режиме
docker compose up -d --build
```

### Шаг 4: Откройте в браузере

```
http://localhost:8501
```

### Остановка сервиса

```bash
docker compose down
```

## 📖 Использование

### Чат с LLM

1. Выберите провайдера (Ollama/vLLM) и модель
2. Настройте системный промпт (опционально)
3. Начните диалог

### Анализ документа

1. Перейдите на вкладку **"Анализ документа"**
2. Загрузите файл (PDF, DOCX, XLSX, TXT)
3. Настройте параметры:
   - Системный промпт
   - Режим анализа (общий/всплеск обращений)
   - Параметры дробления текста
4. Нажмите **"Старт анализа"**
5. Следите за прогрессом и экспортируйте результат

**Особенности:**
- Прогресс сохраняется автоматически
- При ошибке можно продолжить с места остановки
- Предпросмотр чанков перед анализом
- Автоматическое сжатие резюме при разрастании

### Анализ звонков

1. Перейдите на вкладку **"Анализ звонков"**
2. Загрузите WAV файлы (пакет звонков)
3. Файлы будут автоматически транскрибированы
4. Настройте параметры анализа
5. Получите итоговый отчёт с причинами обращений

## 🔧 Конфигурация

### Переменные окружения

| Переменная | Описание | По умолчанию |
|------------|----------|--------------|
| `TRANSCRIBE_URL` | URL сервиса транскрибации | `http://host.docker.internal:8077/api/v1/transcribe` |
| `TRANSCRIBE_FILE_FIELD` | Имя поля для файла | `file` |
| `OLLAMA_URL` | URL Ollama сервера | `http://host.docker.internal:11434` |
| `VLLM_URL` | URL vLLM сервера | `http://host.docker.internal:8000` |
| `LLM_TIMEOUT_SEC` | Таймаут запросов к LLM | `600` |

### Поддерживаемые LLM провайдеры

- **Ollama** — локальный сервер с нативным API
- **vLLM** — высокопроизводительный inference сервер
- **OpenAI-compatible** — любой OpenAI-совместимый API

## 🎯 Примеры использования

### Анализ PDF отчёта
1. Загрузите PDF в интерфейс
2. Выберите режим "Общий анализ"
3. Укажите финальный запрос: "Составь краткое резюме с ключевыми выводами"
4. Получите структурированный Markdown отчёт

### Анализ транскриптов звонков
1. Подготовьте файл с транскриптами (разделённые `=====`)
2. Выберите режим "Всплеск обращений"
3. Настройте дробление "По разделителю" с паттерном `_{3,}|-{3,}|={3,}`
4. Получите анализ причин обращений

### Анализ аудиозвонков
1. Загрузите пакет WAV файлов
2. Сервис автоматически транскрибирует их
3. Получите анализ с выявлением проблем

## 🛠️ Разработка

### Локальный запуск без Docker

```bash
# Установите зависимости
cd src
pip install -r requirements.txt

# Настройте переменные окружения
export OLLAMA_URL=http://localhost:11434
export VLLM_URL=http://localhost:8000

# Запустите приложение
streamlit run app.py
```

### Структура кода

- `app.py` — главный файл с UI и навигацией
- `analyzer.py` — основная логика анализа документов
- `chunking.py` — алгоритмы разбиения текста на чанки
- `document_extractors.py` — извлечение текста из разных форматов
- `llm_client.py` — взаимодействие с LLM API
- `prompts.py` — промпты для разных режимов работы
- `transcribe_client.py` — взаимодействие с сервисом транскрибации
- `config.py` — загрузка и валидация конфигурации
